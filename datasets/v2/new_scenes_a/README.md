# v2 new_scenes_a

Десять независимых synthetic RGB-кадров, сгенерированных built-in imagegen и просмотренных через `view_image` после каждого вызова. Набор предназначен только для dev: он расширяет вариативность музейных помещений, дистанций, поз и наблюдаемого facing, но не является holdout и не подтверждает качество на реальной камере. Lineage — десять новых одиночных raster-генераций; существующие datasets не изменялись.

Покрытие: пустые исторические залы, научный, космический, художественный, архитектурный, технологический, природный и доступный музей; 0–5 видимых посетителей; фронтальные, профильные и спинные ориентации. Intended-план частично скорректирован по факту: первые два вызова дали два близких пустых исторических варианта, поэтому оба сохранены как разные сцены; плановые шесть и девять посетителей не вошли из-за лимита ровно десяти генераций. Разметка отражает только наблюдаемое изображение: `unknown` не заменён нулём, медицинские и демографические выводы не делаются.
